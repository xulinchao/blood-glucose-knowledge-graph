## 一、工具箱（静态 Web UI）

纯前端 HTML 工具箱，包含 AI 提示词生成器、口播文案生成器、选题库卡片列表、CGM 对比表等。

### 启动

```bash
# 方式 1：纯静态预览（无 /api/fetch-source 拉取原贴能力）
python -m http.server 8080

# 方式 2：开发服务器（带 /api/fetch-source 拉取原贴/字幕能力）
python scripts/dev_server.py 8080
```

浏览器打开 `http://127.0.0.1:8080/`，点击"口播创作台"进入 `site/script-generator.html`。

### 开发服务器 API

- `GET /api/fetch-source?url=...` — 拉取单个 URL 的字幕/正文
- `GET /api/fetch-sources?url=...&url=...` — 批量拉取

## 二、Quartz 笔记站点

基于 Quartz v5 的静态站点生成器，把 `content/` 目录下的 Markdown 笔记渲染成网站。

### 启动

需要 Node ≥22、npm ≥10.9：

```bash
npm ci                          # 安装依赖（首次）
npm run plugins:install         # 安装 Quartz 插件（首次）
npm run build:notes -- --serve  # 构建 + 本地预览
```

### 部署

Push 到 `main` 分支 → GitHub Actions 自动构建 Quartz + 合并工具箱静态文件 → 部署到 GitHub Pages（`bg.purpleiris.cn`）。

## 三、Python 数据管道

### 每日选题采集

```bash
# 推荐：双击 scripts/harvest-now.bat

# 或命令行：
python src/daily_topic_harvest.py                    # 完整采集
python src/daily_topic_harvest.py --skip-xhs         # 跳过小红书
python src/daily_topic_harvest.py --skip-twitter     # 跳过 X
python src/daily_topic_harvest.py --keywords "控糖,糖尿病饮食"  # 自定义关键词
```

**前置条件**：

- Chrome 必须打开
- 小红书 / X / Reddit 必须已登录
- OpenCLI 扩展必须已连接
- Agent Reach 工具链已安装（`~\.agent-reach-venv`）
- `yt-dlp`、`mcporter`、`curl` 可用

**产出**：

```
data/exports/daily-harvest-YYYY-MM-DD.json    # 全量 JSON
data/exports/daily-brief-YYYY-MM-DD.json      # 精选 JSON
data/exports/latest-harvest.json              # 指针
data/exports/latest-brief.json                # 指针
research-daily/YYYY-MM-DD-采集日报.html
research-daily/YYYY-MM-DD-精选日报.html
data/discovered-topics.json                   # 入库（仅 gate.passed + 达标条目）
```

采集平台：权威来源、B站、小红书、知乎、X/Twitter、Reddit、YouTube、V2EX、Exa、Jina。

### 精选日报（单独运行）

```bash
python src/curate_daily_brief.py              # 从最新 harvest JSON 生成
python src/curate_daily_brief.py --date 2026-07-08   # 指定日期
```

> 通常不需要手动运行 —— `daily_topic_harvest.py` 采集完成后会自动调用。

### 口播文案生成

```bash
# 从选题库 ID 生成
python src/generate_script.py --topic-id disc-052 --save

# 从采集数据生成
python src/generate_script.py --from-harvest --url "原贴URL" --save

# 手动指定标题和角度
python src/generate_script.py --title "胰岛素抵抗怎么判断" --angle "..." --save

# 指定平台/时长/人设
python src/generate_script.py --topic-id disc-052 --platform dy --duration 60 --persona expert

# 安全 Lint 未通过时强制保存
python src/generate_script.py --topic-id disc-052 --save --force

# 列出可写稿条目
python src/generate_script.py --list-topics
```

| 参数 | 可选值 |
|------|--------|
| `--platform` | `dy`、`xhs`、`bili` |
| `--duration` | 秒数（15–120） |
| `--persona` | `friendly`、`expert`、`personal`、`surprise` |
| `--cat` | `myth`、`food`、`number`、`action`、`symptom`、`tool`、`story`、`mistake` |
| `--output` | `text`、`json`、`prompt` |
| `--mark-script` | `pending`、`writing`、`done` |
| `--mark-publish` | `pending`、`published` |

输出：`data/scripts/script-日期-序号.json`

### Prompt 生成器

```bash
python src/generate_prompts.py                        # 生成全部（食物+知识）
python src/generate_prompts.py --type food            # 仅食物卡片
python src/generate_prompts.py --type knowledge       # 仅知识卡片
python src/generate_prompts.py --food-id food-001     # 指定单个食物
python src/generate_prompts.py --format mj            # Midjourney 格式
python src/generate_prompts.py --output json          # 输出 JSON
```

## 四、依赖关系图

```
                    scripts/harvest-now.bat
                           │
                    daily_topic_harvest.py
                    (多平台采集 + claim_gate)
                      /              \
         采集日报 HTML           daily-brief JSON
                                     │
                          curate_daily_brief.py
                          (精选日报 HTML/MD)
                                     │
                          (可选) TraeWork 监控日报
                                     │
                          generate_script.py
                          (口播文案 + safety lint)
```

### 严格顺序

1. **采集日报先跑**（`daily_topic_harvest.py`）—— 产出全量 JSON
2. **精选日报自动跟跑**（内部调用 `curate_daily_brief.py`）—— 产出精选 JSON
3. **监控日报**（如需）必须等精选 JSON 存在后才能由 Agent 手动生成 —— **不得跳过采集直接手写**
4. **口播生成**（`generate_script.py`）依赖 `discovered-topics.json` 或最新 harvest JSON

## 五、TraeWork 定时任务

### 任务 1（每日 09:00，必须）

```
命令: I:\Project\血糖知识图谱\scripts\run-daily-harvest.bat
产物:
  - research-daily/YYYY-MM-DD-精选日报.html   ← Agent 默认先看
  - research-daily/YYYY-MM-DD-采集日报.html
  - data/exports/daily-brief-YYYY-MM-DD.json  ← Agent 数据源
  - data/exports/latest-brief.json            ← 指针
```

### 任务 2（手动，依赖任务 1）

Agent 读精选 JSON → 写监控日报。如果 `daily-brief-YYYY-MM-DD.json` 不存在，Agent 必须拒绝执行并提示先跑任务 1。
